# Урок 5. Слои и кэш сборки

Демонстрация кэша слоёв: два файла копируются в разном порядке,
меняем то один, то другой — и смотрим, какие слои Docker пересобирает,
а какие берёт из кэша.

```bash
docker build -t lesson05 .
docker run --rm lesson05
```

Файлы:

- `Dockerfile` — `COPY` «редкого» файла раньше «частого» (правильный порядок)
- `data.txt` — «редкие данные», меняем редко
- `app.sh` — «код приложения», меняем часто
